# Identidade visual do GTRZ System

Os arquivos oficiais serão extraídos de `LOGOS.zip`, localizado na raiz do repositório.

Regras:

- somente arquivos aprovados da marca poderão ocupar esta pasta;
- SVG será preferido para interface;
- PNG será usado apenas quando a arte não possuir versão vetorial adequada;
- nenhum recurso será carregado por URL ou CDN;
- o ícone final do instalador Windows será definido após a seleção da marca principal do pacote.
